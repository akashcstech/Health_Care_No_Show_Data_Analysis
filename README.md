# 📌 Project Overview

Patient appointment no-shows create operational inefficiencies, increase healthcare costs, and delay patient care.

This project performs a comprehensive Exploratory Data Analysis (EDA) to identify patterns associated with patient no-show behavior using a synthetic healthcare dataset.

The project covers data cleaning, visualization, business insight generation, Power BI dashboard development, and executive reporting.

> **Note:** This project focuses on exploratory data analysis (EDA) and business insights. It does **not** build a predictive machine learning model.

---

# 🎯 Business Problem

Healthcare providers lose significant time and revenue due to missed appointments.

The objective is to identify the major factors associated with patient no-shows and provide data-driven recommendations that may help improve appointment attendance.

# 📈 Key Findings

### Overall No-Show Rate

- **No-Show:** ~8.3%
- **Attendance:** ~91.7%

---

### Weak Associations

The following variables showed relatively small differences in no-show rates:

- Age
- Gender
- City
- Neighborhood
- Education
- Employment

---

### Strong Associations

The strongest factors associated with no-show behavior include:

- Waiting Days
- Previous No-Shows
- Reminder Calls
- Patient Satisfaction Score
- Income Level
- Insurance Type
- Weather Condition
- Travel Distance

---

# 💡 Business Recommendations

- Review scheduling policies for appointments with long waiting periods.
- Prioritize reminder programs for patients with previous no-show history.
- Improve patient satisfaction and communication.
- Consider additional support for patients traveling longer distances.
- Strengthen patient communication during adverse weather conditions.
- Monitor high-risk patient groups for proactive follow-up.
